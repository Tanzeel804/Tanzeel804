## 🧩 How I Work
1. **Define goal** — convert visitors to interaction (contact/demo)  
2. **Design mobile-first** — smallest screen first, scale up with CSS Grid/Flexbox  
3. **Build iteratively** — small components, automated deploys (GitHub Pages)  
4. **Optimize & test** — Lighthouse checks, cross-device checks, accessible markup
